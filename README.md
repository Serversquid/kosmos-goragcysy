## EXE Faýlyny Ýükläp Almak

1. Ýokardaky **Actions** goýmasyna git
2. Iň soňky **Build EXE** işini aç
3. Aşakda **Artifacts** bölüminden `KosmosGoragcysy-Windows` ýükläp al
4. `.zip` içindäki `KosmosGoragcysy.exe` faýlyny işlet
